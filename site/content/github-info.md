### Awesome Copilot Workflows
- **daily-issues-report.md**: Generates a daily summary of open issues and recent activity as a GitHub issue.
- **ospo-org-health.md**: Weekly health report for organizations, surfacing stale issues/PRs and contributor leaderboards.
- **weekly-comment-sync.md**: Finds and synchronizes stale code comments or README snippets, opening a draft PR when updates are needed.
